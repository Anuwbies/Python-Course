# Level 1: Python Foundations

**Stage:** Beginner. **Prerequisites:** None beyond basic computer use. **Outcome:** Write, run, and explain a small interactive calculator using only straight-line Python statements.

This level teaches eight focused lessons. Explanations are detailed so you can understand why code behaves as it does. Advanced implementation details are reserved for later levels. You do not need loops, conditions, custom functions, imports, classes, or external packages for any Level 1 submission.

## Working through a lesson

Read the explanation and run the worked examples in a scratch file under `Practice/`. Predict the result before running each example. After reading, work through the predict/explain/modify/debug ladder and the independent task. Use hints only when you need them. Each practice file contains the full assignment and expected output as comments. Write your implementation below those comments.

Compare your output with the lesson's expected output, then ask the assistant to review your saved work. Save attempts in [Practice/](Practice/). Reference scripts are kept separately under [Solutions/](Solutions/).

Independent-task sections contain only the assignment, its inputs and requirements, and expected output. Use this guide for review, solutions, and progress instructions.

Assessment comes from the saved work, its behavior, an explanation of key choices, and a small modification during review.

## Completion standard

- You can launch the correct saved script and interpret a simple error message.
- You can explain variables, types, arithmetic, strings, formatting, and text-to-number conversion.
- Each independent task has been attempted, reviewed, and explained.
- The capstone works for ordinary values, zero costs, uneven splits, and a negative remaining balance.
- You can change one calculation without copying a solution.

Record evidence in [the Level 1 progress file](../../Progress/Level_01_Python_Foundations.md). Reading this guide or running a supplied solution is not student completion.

## Where this level stops

Programs here assume the specified valid input types and ranges. You will observe errors for invalid conversion, but recovery with exceptions belongs to Level 4. Decisions and repeated input arrive in Level 2; custom functions arrive in Level 3. For Level 1, a negative balance is displayed as a number rather than classified with an `if` statement.
