> 1. Asynchronously crawls thousands of URLs concurrently using `asyncio` and non-blocking HTTP sockets
> 2. Rate-limits network traffic using `asyncio.Semaphore`
> 3. Stores inverted document indices in a custom Trie / Graph data structure
> 4. Dispatches CPU-heavy natural language processing and token parsing across multiple CPU cores with `ProcessPoolExecutor`
