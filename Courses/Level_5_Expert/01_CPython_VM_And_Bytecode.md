To master Python at the highest level, you must understand how Python source code is tokenized, parsed into an Abstract Syntax Tree (AST), compiled into Bytecode, and evaluated by the CPython virtual machine.

## 1. Disassembling Python Functions (`dis`)

Python compiles `.py` files into code objects containing bytecode instructions:

```python
import dis

def calculate(a, b):
    x = a * 2
    return x + b

# Print raw bytecode instructions
dis.dis(calculate)
```

### Output Explanation:
```text
  Line  Offset  OpCode           Arg  Meaning
     2       0  LOAD_FAST          0  (Push variable 'a' onto the value stack)
             2  LOAD_CONST         1  (Push constant 2 onto the value stack)
             4  BINARY_OP          5  (Pop both, multiply them, push result)
             8  STORE_FAST         2  (Pop and store into local variable 'x')

     3      10  LOAD_FAST          2  (Push 'x' onto stack)
            12  LOAD_FAST          1  (Push 'b' onto stack)
            14  BINARY_OP          0  (Pop both, add them, push result)
            18  RETURN_VALUE          (Pop and return top of value stack)
```

## 📝 Quick Exercise

**Prompt**:
Disassemble a list comprehension `[x*2 for x in nums]` and compare its generated bytecode against a standard `for` loop calling `list.append()`. Notice why list comprehensions execute faster at the C level.

<details>
<summary><b>🔍 View Exercise Solution</b></summary>

```python
import dis

def loop_append(nums):
    res = []
    for x in nums:
        res.append(x * 2)
    return res

def list_comp(nums):
    return [x * 2 for x in nums]

print("=== Loop with append Bytecode ===")
dis.dis(loop_append)

print("\n=== List Comprehension Bytecode ===")
dis.dis(list_comp)

# Notice: list_comp utilizes specialized LIST_APPEND opcodes that bypass the Python-level method lookup overhead of res.append()!
```
