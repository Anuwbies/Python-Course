## 🏆 Level 1 Capstone Project: Object-Oriented Banking System
> **Project Scope**:
> Build an interactive, menu-driven banking CLI application that tests all 10 lessons:
> 1. Input parsing and type casting for deposits and withdrawals
> 2. Interest calculation and account validation using operators and conditionals
> 3. Account collections and transaction history stored in lists and dictionaries
> 4. Structured object-oriented models (`Account`, `Customer`, `Bank`)
> 5. Safe file persistence to store and reload transaction logs from disk
> 6. Robust error handling with `try...except` preventing crashes from invalid input or insufficient funds
