## 🎯 Learning Evaluation Rubric
When implementing any Level 1 project, ensure your solution satisfies:
- **Clean Code & Formatting**: PEP 8 snake_case conventions, readable variable names, f-string output.
- **Defensive Programming**: Handle all bad user inputs (`ValueError`, `FileNotFoundError`, out-of-range choices) without crashing.
- **Data Persistence**: Correctly save and load system state to/from disk using CSV or JSON.
- **Modular Structure**: Divide code into logical functions or classes with single responsibilities.
